How each room works

Every room follows the same shape, so once you know one, you know them all. Each one is a single page: no installs, no accounts, nothing to configure.

  1. 1. LearnA short, beginner-friendly theory section with analogies and a mini quiz.
  2. 2. PractiseA safe, simulated target site with tasks that build in difficulty.
  3. 3. CaptureDecode or discover a flag and submit it for instant feedback.
  4. 4. EvidenceDownload a results file with your answers and flag status for Canvas.

Before you start

Every target in every room is fictional and fully simulated in your browser. Only ever test real systems you own or have explicit permission to test — accessing real systems without authorisation is a criminal offence under the Computer Misuse Act 1990.
